# ClimateCopilot AI

## Vision

ClimateCopilot AI is an open-source platform that helps governments and public administrations make better climate-related decisions using artificial intelligence.

## Goals

- Analyze climate data
- Generate automatic reports
- Support public decision making
- Reduce analysis time
- Improve climate resilience

## Roadmap

### Version 0.1
- Basic project structure
- Climate data module
- Report generator

### Future
- AI assistant
- Interactive maps
- Risk prediction
- Dashboard
- Public APIs
